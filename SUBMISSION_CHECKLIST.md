# Millennium submission checklist

The source repository is prepared for public GitHub hosting. Before submitting the **Submit a Theme** issue to Millennium, verify the following:

- [ ] GitHub repository is public: `guyonphone/UltraWide`.
- [ ] `skin.json` points to the correct GitHub owner and repository name.
- [ ] The latest tested release is committed and pushed.
- [ ] Add final SteamBrew `header_image` artwork and its `skin.json` metadata.
- [ ] Add final SteamBrew `splash_image` artwork and its `skin.json` metadata.
- [ ] Review the current Millennium submission form for any additional required listing metadata.
- [ ] Test a clean install from the GitHub repository rather than from the local development folder.
- [ ] Test the main Store homepage infinite feed.
- [ ] Test several individual game pages with different purchase-box layouts.
- [ ] Test review filtering, internal scrolling, See More Reviews, page-scroll handoff, and graph hide/show.
- [ ] Open the Millennium repository's **Submit a Theme** issue and provide the public repository requested by the template.
